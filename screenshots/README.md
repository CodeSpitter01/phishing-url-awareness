# Required screenshots

The workbook requires two genuine screenshots captured from the student's own computer. They are intentionally not fabricated or pre-filled in this folder.

## 1. `sample_run.png`

1. Open a terminal in the project folder.
2. Run `python3 phishing_checker.py` on Mac/Linux (or `python phishing_checker.py` on Windows).
3. Enter `http://192.0.2.10/account` and leave the result visible.
4. On Mac, press `Command + Shift + 4` and select the terminal area. Save the image here as `sample_run.png`.

The screenshot should show the project-folder terminal, command, entered sample and printed findings.

## 2. `test_results.png`

1. Open `tests/test_samples.md` in VS Code or another editor after you have re-run the five workbook samples.
2. Make the complete five-row table readable (zoom in if needed).
3. On Mac, press `Command + Shift + 4` and select the table area. Save the image here as `test_results.png`.

The screenshot should show all five test rows and their PASS/FAIL results. Do not include passwords, private email addresses, tokens or unrelated private information.
